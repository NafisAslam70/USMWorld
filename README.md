# USMWorld

USMWorld is a student-community web project designed as a single place for people connected to Universiti Sains Malaysia to find useful campus information and resources.

## About
The repository contains the original USMWorld web experience and a web panel. The project aims to bring university-related resources and community information together rather than making users search across separate pages.

## Repository
- `USMWorld finalR/` — web application files
- `USMWorldWebPanel/` — web panel

Open the folders to inspect the respective implementations. This repository currently has limited setup documentation; framework and run instructions depend on the files in each subproject.
